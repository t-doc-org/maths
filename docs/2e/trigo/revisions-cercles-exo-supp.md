## Équations et cercle trigonométrique

### Exercice {nump}`exercice`

En vous aidant du cercle trigonométrique, cochez les bonnes réponses.

````{quiz}
{.lower-alpha-paren}
1.  ```{defaults} quiz-check
    :multi:
    :randomize:
    :class: columns-3
    :right: width: 60%;
    ```
    ```{quiz-check}
    - :$x = 30^\circ$
    - $x = 45^\circ$
    - :$x = \frac{\pi}{6}$
    ```
    $\sin(x) = \frac{1}{2}$
2.  ```{quiz-check}
    - $x = 45^\circ$
    - :$x = \frac{\sqrt{2}}{2}$
    - :$x = \sin(\frac{\pi}{4})$
    ```
    $\cos(\frac{\pi}{4}) = x$
3. ```{quiz-check}
    - $x = 30^\circ$
    - :$x = 60^\circ$
    - :$x = 240^\circ$
    ```
    $\tan(x) = \sqrt{3}$
4.  ```{quiz-check}
    - $x = 1$
    - :$x = 0$
    - :$x = 2\pi$
    ```
    $\sin(x) = 0$
5.  ```{quiz-check}
    - :$x = 45^\circ$
    - $x = 45^\circ + 180^\circ$
    - :$x = \frac{\pi}{4} + 2\pi$
    ```
    $\cos(x) = \frac{\sqrt{2}}{2}$
6. ```{quiz-check}
    - :$x = \frac{\pi}{6}$
    - :$x = 30^\circ$
    - :$x = 210^\circ$
    ```
    $\tan(x) = \frac{\sqrt{3}}{3}$
7.  ```{quiz-check}
    - $x = 45^\circ$
    - :$x = -60^\circ$
    - :$x = 300^\circ$
    ```
    $\sin(x) = -\frac{\sqrt{3}}{2}$
8.  ```{quiz-check}
    - :$x = 1$
    - :$x = 2\pi$
    - $x = 0$
    ```
    $\cos(x) = 0$
9. ```{quiz-check}
    - :$x = 225^\circ$
    - $x = 45^\circ$
    - :$x = 315^\circ$
    ```
    $\tan(x) = -1$
````
