## Exercice {nump}`exercice`

Résolvez les équations suivantes:

{.lower-alpha-paren}
1. $4x+5=13$
2. $3(x+2)=2x-1$
3. $3x-7=-\frac{5}{2}x+\frac{5}{4}$
4. $2(x+15)=8x+30-6x$
5. $16-36x=-3(12x+1)$

```{solution}
{.lower-alpha-paren .columns-5}
1.  $S = \{2\}$
2.  $S = \{-7\}$
3.  $S = \{\frac{3}{2}\}$
4.  $S = \mathbb{R}$
5.  $S = \varnothing$
```


## Exercice {nump}`exercice`

Trois amis collectionnent des BD. John possède trois fois plus de BD que Ben.
Mandy possède 10 BD de moins que Ben. Au total, ils ont 100 BD. Laquelle de ces
équations permet de déterminer le nombre de BD que chacun possède?<br>
Que représente la lettre $x$?

$\square \quad 3x-10=100$

$\square \quad 3x+(x-10)=100$

$\square \quad x=\dfrac{100+10}{5}$

$\square \quad x+3x+(x-10)=100$

```{solution}
Inconnue: soit $s$ le nombre de BD de Ben

$x=\dfrac{100+10}{5}$ et $x+3x+(x-10)=100$
```

## Exercice {nump}`exercice`

Dans le centre de tennis $A$, la location d'un court de tennis pendant une heure
coûte CHF 28.-. Le centre de tennis $B$ demande une taxe forfaitaire annuelle de
CHF 200.-, ensuite l'heure de tennis ne coûte que CHF 18.-.

{.lower-alpha-paren}
1.  Quel centre de tennis choisirais-tu pour jouer?
    {vspace}`2lh`
2.  Déterminez, pour chaque centre, une formule qui calcule le coût total pour
    jouer au tennis en fonction des heures $x$ passées sur un court.
    {vspace}`2lh`
3.  Pour combien d'heures, les deux centres ont le même coût?
    {vspace}`2lh`

```{solution}
{.lower-alpha-paren}
1.  Cela dépend du nombre d'heures jouées.
2.  Centre A: $28x$<br>
    Centre B: $18x + 200$
3.  Il faut résoudre $28x = 18x + 200$<br>
    $x = 20 \implies S = \{20\}$<br>
    Le coût est le même pour 20 heures.
```
